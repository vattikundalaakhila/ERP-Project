# 📊 ERP Management System

![HTML](https://img.shields.io/badge/HTML-5-orange)
![CSS](https://img.shields.io/badge/CSS-3-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![Status](https://img.shields.io/badge/Project-Frontend%20Only-green)

A **simple ERP (Enterprise Resource Planning) web application** built using **HTML, CSS, and JavaScript**.
The system allows users to manage **inventory, sales, and employees**, along with a **dashboard that visualizes business data using charts**.

This project simulates a **basic business management system** where product inventory, sales transactions, and employee data are interconnected.

---

# 🚀 Features

## 🔐 Authentication System

* User registration
* Secure login system
* Access to ERP modules only after successful login

---

## 📊 Dashboard

The dashboard provides a quick overview of business data.

Features:

* Product statistics
* Sales insights
* Employee overview
* Interactive charts and visual analytics

---

## 📦 Inventory Management

Manage all products in the system.

Capabilities:

* Add new products
* Edit existing products
* Delete products
* View product stock levels

---

## 💰 Sales Management

Sales module directly connects with the inventory.

Features:

* Select products from inventory
* Record sales transactions
* Automatically update product stock
* Maintain sales records

---

## 👨‍💼 Employee Management

Manage employee information.

Features:

* Add employee details
* View employee list
* Assign employee roles

# ⚙️ How the System Works

1️⃣ User registers an account.
2️⃣ After registration, the user logs into the system.
3️⃣ The system redirects the user to the **dashboard**.
4️⃣ From the dashboard, the user can navigate to:

* Inventory
* Sales
* Employees

All application data is stored using **localStorage**, allowing the system to persist data even after refreshing the page.
